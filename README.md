# Bone Byte Tech website

Static publisher homepage for Bone Byte Tech. SeaFetch, WearStream, and Side by Set link to their own sites.

Preview locally from this directory with `python -m http.server 8819`. GitHub Pages publishes the root of the main branch. App names and artwork belong to their respective projects.

The Side by Set app icon and shared-session illustration come from the Side by Set project. See the [included MIT notice](assets/side-by-set-LICENSE.txt).
